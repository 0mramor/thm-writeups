## Что изучил
Первое знакомство с командной строкой Linux — базовая навигация и работа с файлами.

## Команды, с которыми познакомился

| Команда | Назначение |
|---|---|
| `pwd` | показать текущую директорию |
| `ls` | посмотреть содержимое папки |
| `cd` | перейти в другую папку |
| `cat` | вывести содержимое файла |
| `find` | найти файл по системе |
| `df -h` | посмотреть свободное место на диске |
| `du -sh` | посмотреть размер конкретной папки |

## Заметки
- `find ~ -name файл.txt` — ищет файл начиная от домашней папки, быстрее и чище, чем искать от корня `/`
- При поиске от корня диска (`find /`) без прав администратора терминал выдаёт много `Permission denied` — это нормально, просто означает, что в системные папки нет доступа. Чтобы скрыть эти ошибки, можно добавить `2>/dev/null`
- В выводе команд типа `find` не бывает "шаблонов" — если команда показала реальный путь, его и нужно использовать как есть
