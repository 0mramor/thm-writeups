## Что изучил
Кодирование данных (encoding) — смена формата данных без потери информации и без секретности. Отличие encoding от encryption и hashing. Кодировки текста: ASCII, Unicode, UTF-8/16/32.

## Ключевые концепции

**Encoding vs Encryption vs Hashing**
| Тип | Обратимость | Назначение |
|---|---|---|
| Encoding (Base64, URL, Hex) | Обратимо без ключа | Удобство передачи/хранения данных |
| Encryption | Обратимо только с ключом | Защита данных |
| Hashing | Необратимо | Проверка целостности, хранение паролей |

**Base64** — кодирует бинарные данные в текст (буквы, цифры, `+`, `/`, `=`). Используется, когда нужно передать бинарные данные там, где ожидается только текст (email, JSON, URL). Не является шифрованием: раскодировать может любой без пароля.

**URL Encoding** — заменяет спецсимволы на `%XX` (hex-код символа), потому что URL не может содержать их напрямую. Пример: пробел → `%20`.

**Unicode и UTF-кодировки:**
- Unicode — таблица, где у каждого символа всех языков мира есть уникальный номер (code point), записывается как `U+XXXX`
- UTF-8 / UTF-16 / UTF-32 — разные способы записать этот номер в байты
- UTF-8: латиница = 1 байт (совместим с ASCII), редкие символы = 2-4 байта. Стандарт в интернете
- UTF-16: большинство символов = 2 байта фиксированно. Используется в Windows, Java
- ASCII — более старый и узкий стандарт (128 символов, только латиница), Unicode создан, чтобы охватить все языки

**Хеширование (закрепил из предыдущей темы):**
- Хеш нельзя "прочитать" обратно — это односторонняя функция
- Взлом хеша = подбор (brute-force/словарные атаки, hashcat, John the Ripper), а не расшифровка
- Пароли хранят как хеш и сверяют новый ввод с сохранённым хешем — компания не знает исходный пароль
- Данные, которые нужно прочитать обратно (например, номер карты) — хранят зашифрованными (encryption), а не хешированными

## Заметки
- Проблема "кракозябр" (mojibake) в файлах/программах обычно возникает не из-за Unicode, а из-за несовпадения кодировки при сохранении и при открытии файла (например, файл в Shift-JIS или Windows-1251 открывают как UTF-8)
