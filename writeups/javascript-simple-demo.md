## JS vs Python — ключевые отличия
| | Python | JavaScript |
|---|---|---|
| Блоки кода | Отступы | Фигурные скобки `{ }` |
| Конец строки | Не нужен | `;` |
| Переменные | Просто `x = 5` | `let x = 5;` (изменяемая) или `const x = 5;` (неизменяемая) |
| Условие | `if x > 5:` | `if (x > 5) {` |
| Вывод | `print()` | `console.log()` |
| Ввод с консоли | `input()` из коробки | Нужен модуль `readline`, плюс `await` |

## Ключевые концепции
- **Node.js** — среда выполнения, позволяющая запускать JS вне браузера (как `python3` для .py файлов): `node файл.js`
- **let vs const** — `let`, если значение будет меняться; `const`, если нет
- **try/finally** — гарантирует выполнение кода (например, закрытие `readline`) независимо от того, была ошибка или нет
- **Math.random()** — даёт случайное дробное число от 0 до 1; чтобы получить случайное целое в диапазоне, нужно вручную умножать, `Math.floor()` и прибавлять сдвиг (в Python это `random.randint()` одной функцией)
- **parseInt(text, 10)** — аналог `int()` из Python, `10` означает десятичную систему
