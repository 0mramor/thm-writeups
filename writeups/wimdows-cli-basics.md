## Что изучил
Базовые команды Windows CLI (CMD) — навигация и информация о системе. Прошло легче, чем Linux CLI Basics, так как логика команд уже знакома.

## Команды, с которыми познакомился

| Команда | Назначение | Аналог в Linux |
|---|---|---|
| `cd` | перейти в папку | `cd` |
| `dir` | посмотреть содержимое папки | `ls` |
| `ipconfig` | показать сетевые настройки | `ifconfig` / `ip addr` |
| `whoami` | показать текущего пользователя | `whoami` |

## Заметки
- В Windows пути через обратный слеш `\`, в Linux — через прямой `/`
- В Windows есть буквы дисков (C:, D:), в Linux всё начинается от одного корня `/`
